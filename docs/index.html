Por que este fork existeWhy this fork exists

Nossos usuários entram no GLPI pelo SSO corporativo, com o plugin samlSSO. Mesmo assim, a tela de login continuava mostrando usuário e senha em destaque, e o botão de SSO ficava pequeno, abaixo do formulário, com o nome do provedor cortado em 12 caracteres. Quem só precisava clicar em um botão acabava digitando a senha no lugar errado.

O Brandkit já resolvia a identidade visual: logos, cores, layouts e papel de parede da tela de login. Faltava o encaixe com o SSO. Este fork acrescenta um modo SSO que esconde os campos locais e coloca o botão no centro, sem tirar o acesso dos administradores: as contas locais continuam entrando por um endereço próprio.

No caminho, corrigimos problemas de layout que apareceram em produção e revisamos a segurança do plugin. Publicamos o resultado para que outras equipes não precisem começar do zero.

Our users sign in to GLPI through corporate SSO, using the samlSSO plugin. Even so, the login page kept the username and password fields front and center, while the SSO button sat small under the form, with the provider name cut to 12 characters. People who only needed to click a button ended up typing their password in the wrong place.

Brandkit already handled the visual identity: logos, colors, layouts and the login wallpaper. What it lacked was a fit with SSO. This fork adds an SSO mode that hides the local fields and puts the button in the middle, without locking administrators out: local accounts still sign in at their own address.

Along the way we fixed layout issues found in production and reviewed the plugin's security. We are publishing the result so other teams don't have to start from scratch.

Tudo do Brandkit, mais o que o SSO pediaEverything in Brandkit, plus what SSO needed

Modo SSOSSO mode

  • Esconde usuário e senha e coloca o botão SSO no lugar, com o estilo do botão de login.
  • Só age quando há um botão SSO na página. Se o samlSSO for desativado, o formulário normal volta sozinho.
  • Acesso local em ?bypass=1&noAUTO=1, o mesmo endereço de bypass do samlSSO. Nessa página, o botão SSO some.
  • Texto, ícone e cores do botão configuráveis.
  • Hides username and password and puts the SSO button in their place, styled like the login button.
  • Only acts when an SSO button is on the page. If samlSSO is disabled, the normal form comes back on its own.
  • Local access at ?bypass=1&noAUTO=1, the same bypass address samlSSO uses. That page hides the SSO button.
  • Configurable button text, icon and colors.

CorreçõesFixes

  • Layout das telas de autenticação em dois fatores (issue #4 do original).
  • Rodapé de copyright, botões das mensagens de erro e botão FAQ alinhados à área de login.
  • Tela de login ajustada para celular.
  • Two-factor authentication page layout (issue #4 on the original).
  • Copyright footer, error message buttons and FAQ button aligned with the login area.
  • Login page fixed for phones.

Segurança e manutençãoSecurity and upkeep

  • Imagens enviadas são validadas e reprocessadas; arquivos disfarçados de imagem são recusados.
  • Backup e restauração dos logos originais do GLPI.
  • Instalação pelo marketplace do GLPI 11.
  • Tradução pt_BR completa.
  • Uploaded images are validated and re-encoded; files disguised as images are rejected.
  • GLPI's original logos are backed up and restored.
  • Installs from the GLPI 11 marketplace folder.
  • Full pt_BR translation.
InstalaçãoInstall

Três passos até o primeiro loginThree steps to the first sign-in

  1. Coloque o plugin na pasta de plugins do GLPIPut the plugin in GLPI's plugin folder

    Baixe o zip em Releases ou clone o repositório. A pasta precisa se chamar brandkit, dentro de plugins/ (ou marketplace/ no GLPI 11). Download the zip from Releases or clone the repository. The folder must be named brandkit, inside plugins/ (or marketplace/ on GLPI 11). 

    git clone https://github.com/kibinluck/brandkit-plus-sso.git brandkit
  2. Instale e habiliteInstall and enable

    No GLPI: Configurar › Plugins, depois Instalar e Habilitar. In GLPI: Setup › Plugins, then Install and Enable.

  3. Ligue o modo SSOTurn on SSO mode

    Em Plugins › Brandkit Plus SSO › Página de login, ative o modo SSO, ajuste o botão e guarde o endereço de acesso local. In Plugins › Brandkit Plus SSO › Login Page, turn on SSO mode, adjust the button and keep the local access address somewhere safe.

Já usa o Brandkit original? A chave do plugin é a mesma (brandkit). Basta substituir a pasta: as configurações e as imagens continuam lá.

Already using the original Brandkit? The plugin key is the same (brandkit). Replace the folder and your settings and images stay in place.
